# 原生同功能设置优先（0.2.5 测试）

模块先检查已安装 Gboard 的实际偏好 XML，按原生设置键和控件类型判断是否等价，不按版本号隐藏，不靠标题模糊匹配。扫描覆盖 base 和资源 split；文件名和设置键资源编号允许混淆。结果按 APK 路径/大小/时间缓存，更新、降级或重装后重新检测；无法读取或无法确认等价时保留模块开关。

原生设置属于动态界面，资源中存在控件并不保证所有账号、语言或服务开关下都可见；本轮检测依据为实际安装包里的原生控件定义。后端功能资格仍由 Gboard 决定。

| 模块功能 | 等价原生控件证据 | 18.4.6 处理 |
| --- | --- | --- |
| 快捷表情栏 | `enable_fast_access_bar` + SwitchPreference | 隐藏模块项，遵循原生“表情符号快速访问行” |
| Magic Emoji | `enable_emojify` + SwitchPreference | 隐藏模块项，遵循原生“文字转表情” |
| 表情大小入口 | `keyboard_emoji_scale_setting` + EmojiScaleSliderPreference | 隐藏模块项，使用原生大小滑块 |
| 撤销按钮 | 原生只有 `pref_key_latin_enable_ac_revert`（退格撤销纠错） | 功能不同，保留候选栏/语音撤销增强 |
| Google Sans Flex 与主题 | 原生 `use_system_font` 是系统字体选择，不等于三个字体/表现力主题标志 | 保留增强 |
| 输入时联想表情 | 原生“显示表情”是总开关，模块调整 concept prediction 等额外策略 | 保留增强且不覆盖原生总开关 |
| 剪贴板保留时长 | 原生 slider 的 entryValues 为 1/2/3/6/12/18/24 小时 | 保留模块 7 天/30 天/100 年扩展；仅当原生范围覆盖全部扩展值时隐藏 |
| 截图浮动建议 | 原生“保存最近截图到剪贴板”不等于浮动建议横幅 | 保留横幅增强；存在该原生控件时不再覆盖同名截图保存 flag |
| 其他功能 | 未确认有作用完全等价的原生控件 | 保留 |

以上来自用户提供的 Gboard 18.4.6 APK（176027358）。生产代码使用实际检测结果，上述版本仅为本次审计记录，不是版本判断条件。

隐藏不只是 UI：同步时屏蔽对应模块值，Gboard 进程也独立检测并忽略旧的已开启值；原生偏好读取 Hook 和共享 flag Hook 均不再应用这些隐藏功能的策略。不改写 Gboard 的开关值。模块旧配置可保留供不含原生控件的版本使用，诊断显示“遵循 Gboard 原生设置”，并记录 NATIVE_SETTINGS。

测试覆盖原生键/控件类型确认、缺失时保留、范围不等价、旧配置无法覆盖、实际模块 UI 隐藏/恢复。首次更新模块后请重启 Gboard，让此前缓存的策略返回值重新读取。未发布 Release。
