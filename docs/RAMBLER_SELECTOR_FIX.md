# Rambler 设置入口恢复（0.2.2 测试）

用户在 Gboard 18.4.4 上反馈键盘入口与语音设置选项同时消失。0.2.1 日志显示 Hook 安装成功，但没有记录 Rambler 原生选择值，因此不能直接认定故障原因。

代码检查发现一个可复现的问题：`enable_jetson=false` 的判断早于语音设置作用域判断，导致用户关闭功能后，设置入口本身也可能失去模块提供的显示条件。修复将设置作用域优先处理，保留官方选择器供用户重新选择；普通运行仍遵循原生关闭值，不写入 Gboard 偏好，也不强制激活语音。

同时，原生选择恢复为 true 后立即优先使用该值，避免旧的 false 观察值继续阻断功能。默认选择初始化作用域仍不强制启用。

开启模块诊断后，新日志包含 `RAMBLER_SELECTION` 与 `RAMBLER_FLAG`：记录原生选择值、已观察的选择值、作用域、标志类型及是否改写。事件按进程内不同状态去重，不读取语音或输入文本。

验证：自动回归覆盖关闭状态下设置可见但运行仍关闭、嵌套默认作用域、重新选中后解除旧状态、缺省值与瞬时 false。实机仍需检查设置入口是否恢复，并由用户主动选择后验证语音；Hook 成功不等于后端可用。
